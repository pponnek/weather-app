# Weather Dashboard Vue 3

Aplikasi dashboard cuaca responsive menggunakan **Vue 3**, **Vite**, dan **PrimeVue**.  

Fitur utama:
- Cari dan tampilkan data cuaca beberapa kota
- Suhu dalam °C / °F
- Auto-refresh per kota atau semua kota
- Hapus kota tunggal atau semua kota
- Grafik riwayat suhu
- Layout responsive untuk desktop & mobile
